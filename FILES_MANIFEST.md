## 💾 Data Storage Strategy

### LocalStorage (Built-In)
- **Where:** Browser's localStorage on your device
- **What:** All CPD entries (JSON format)
- **Size:** ~50 bytes per entry (for typical clinical notes)
- **Limit:** ~5-10 MB per website (ample for thousands of entries)
- **Persistence:** Survives browser restart, cleared only if you manually clear cache

### Storage Keys
- `npCpdLogger_entries` - Array of all CPD entries
- `npCpdLogger_settings` - App settings (student name, ID, auto-backup)

### Backup Strategy (Recommended)
1. **Weekly JSON Export** (Settings → Backup as JSON)
2. **Store in cloud** (OneDrive, Google Drive, etc.)
3. **Keep Excel exports** from university submissions

### Cross-Device Sync
- No automatic cloud sync
- Manual sync via JSON backup/restore
- Optional: Future Supabase integration (advanced users)
