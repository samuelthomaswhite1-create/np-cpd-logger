🔧 TROUBLESHOOTING:
================================================================================

Problem: "Entries disappeared after refresh"
→ Solution: Browser cleared LocalStorage. Check Settings → Privacy.
           Export as JSON backup weekly to prevent this.

Problem: "De-ID check flags legitimate clinical language"
→ Solution: By design (privacy-first). Use abbreviations:
           Bad: "Jane Smith, DOB 01/01/1985, chest pain"
           Good: "50yo F with dyspnea, UR-12345"

Problem: "App won't install on mobile"
→ Solution: Force refresh (Ctrl+Shift+R), wait 30 seconds, clear cache.

Problem: "Excel export has wrong columns"
→ Solution: Edit exportToExcel() function in index.html to match template.
           See SETUP.md for column mapping guide.

Problem: "Can't select multiple standards"
→ Solution: Click each standard button individually to toggle on/off.
           Multiple selections ARE supported.

📊 EXPORTING TO MONASH TEMPLATE:
================================================================================

STEP 1: Prepare Your Template
  • Download Template CPD Log.xlsx from Monash
  • Open it (don't edit, just verify structure)
  • Note which row data starts (usually Row 5)

STEP 2: Export from App
  • Settings tab → "📊 Export to Monash CPD Excel Template"
  • Select your Template CPD Log.xlsx file
  • Click Open

STEP 3: Verify Download
  • Check Downloads folder for CPD_Log_YYYY-MM-DD.xlsx
  • Open it in Excel to verify entries are in correct columns
  • All other sheets (student details, mentors, etc.) are preserved

STEP 4: Submit to University
  • Rename to final format required (e.g., "FirstName_LastName_CPD_Log.xlsx")
  • Submit through Monash learning management system
  • Keep a copy for your records

🔄 SYNCING BETWEEN DEVICES:
================================================================================

Mobile ←→ Desktop Sync via JSON Backup:

Desktop → Mobile:
  1. Desktop: Settings → "💾 Backup as JSON"
  2. Move file to OneDrive/Google Drive
  3. Mobile: Download from cloud storage
  4. Mobile: Settings → "📤 Restore from JSON"
  5. Select downloaded file

Mobile → Desktop:
  1. Mobile: Settings → "💾 Backup as JSON"
  2. Move file to OneDrive/Google Drive
  3. Desktop: Download from cloud storage
  4. Desktop: Settings → "📤 Restore from JSON"
  5. Select downloaded file

Note: Backups MERGE with existing data (no data loss).
